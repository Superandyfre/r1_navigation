# 机械臂自体回波修复记录

目标是在不连接底盘、不执行实机运动的条件下完成姿态一致性、传感器时间对齐、
三维过滤及连续性验证。当前 UI7 仍指向 v7，开发构建未部署。

## 阶段一：姿态和缓存

缓存验证改为比较全部部件 TF，包括臂关节未变化时的夹具部件变换；平移或旋转
超过阈值重新投影，稳定 TF 复用缓存。单次 TF 短缺仅在原几何与现有臂关节相容、
并且最近一次成功验证仍在有效期内时沿用；持续过期或姿态不相容时不再用旧几何
过滤，并发布降级/故障原因。关节状态要求 1–7 号各一次、有限值、非过期且时间
递增，重复或陈旧消息不能延长有效期。采样时钟倒退后允许重新建立时间序列。

隔离 ROS 域 197 启动真实轮廓节点，模拟 36 个部件 TF 和双臂关节：夹具独立运动
更新投影；短时 TF 缺失持续输出，持续过期后不再发布旧几何；恢复后继续输出；
不断发送过期关节时间戳和重复关节名均不能延长有效期，恢复新鲜消息可恢复。
另有 TF 位姿比较单测。TF 丢失、重算和过滤性能仍需与整个真实求解链联合验证。

只读采样：前雷达 /lidar/pointcloud 有 float64 逐点 timestamp，样本值为绝对纳秒；
后雷达 /scan 样本有 2400 束、约 28.34 微秒 time_increment、约 68 毫秒扫描时间。
当前双臂关节采样年龄分别不超过约 4.4 ms / 84.3 ms；这只是一次抽样，不是上限。

## 未完成

## 三维查询和时间分组的独立基础

增加独立的三角网格表面接近查询和传感器时间分组组件；二维坐标相同、高度不同的
测试点可区分，前雷达绝对纳秒时间和后雷达逐束时间计算、异常输入检查有单测。
查询当前只判断距离网格表面是否在容差内，**不判断封闭体内部**，也尚未用于实际
扫描；不能作为完整过滤器或证明无漏滤。

离线使用 36 个真实部件网格、每帧 20000 个合成点测试，构建索引约 4.63 秒，
三帧查询平均约 5.36 ms/帧。该结果不含 TF 查询、时间分组、ROS 序列化、实际点云
分布和真实导航负载，不能当作端到端时延上界。过滤链、历史姿态插值、降级处理、
标注回放和实际求解链连续性验证仍待完成。
