# 机械臂自体回波修复记录

目标是在不连接底盘、不执行实机运动的条件下完成姿态一致性、传感器时间对齐、
三维过滤及连续性验证。当前 UI7 仍指向 v7，开发构建未部署。

## 阶段一：姿态和缓存

缓存验证改为比较全部部件 TF，包括臂关节未变化时的夹具部件变换；平移或旋转
超过阈值重新投影，稳定 TF 复用缓存。单次 TF 短缺仅在原几何与现有臂关节相容、
并且最近一次成功验证仍在有效期内时沿用；持续过期或姿态不相容时不再用旧几何
过滤，并发布降级/故障原因。关节状态要求 1–7 号各一次、有限值、非过期且时间
递增，重复或陈旧消息不能延长有效期。采样时钟倒退后允许重新建立时间序列。

隔离 ROS 域 197 启动真实轮廓节点，模拟 36 个部件 TF 和双臂关节：夹具独立运动
更新投影；短时 TF 缺失持续输出，持续过期后不再发布旧几何；恢复后继续输出；
不断发送过期关节时间戳和重复关节名均不能延长有效期，恢复新鲜消息可恢复。
另有 TF 位姿比较单测。TF 丢失、重算和过滤性能仍需与整个真实求解链联合验证。

只读采样：前雷达 /lidar/pointcloud 有 float64 逐点 timestamp，样本值为绝对纳秒；
后雷达 /scan 样本有 2400 束、约 28.34 微秒 time_increment、约 68 毫秒扫描时间。
当前双臂关节采样年龄分别不超过约 4.4 ms / 84.3 ms；这只是一次抽样，不是上限。

## 未完成

扫描时刻 TF 插值、前三维点云与后雷达截面过滤、带标注回放及连续性负载验证尚未
实现。不能把阶段一称为整套修复完成，也不能根据开发构建切换 UI7。

## 三维查询和时间分组的独立基础

增加独立的三角网格表面接近查询和传感器时间分组组件；二维坐标相同、高度不同的
测试点可区分，前雷达绝对纳秒时间和后雷达逐束时间计算、异常输入检查有单测。
查询当前只判断距离网格表面是否在容差内，**不判断封闭体内部**，也尚未用于实际
扫描；不能作为完整过滤器或证明无漏滤。

离线使用 36 个真实部件网格、每帧 20000 个合成点测试，构建索引约 4.63 秒，
三帧查询平均约 5.36 ms/帧。该结果不含 TF 查询、时间分组、ROS 序列化、实际点云
分布和真实导航负载，不能当作端到端时延上界。过滤链、历史姿态插值、降级处理、
标注回放和实际求解链连续性验证仍待完成。

## 三维影子链与离线初测

新增独立影子节点，只订阅原始前点云和后扫描，按各自逐点/逐束时间分组查询 TF；
仅发布 /r1_self_filter_3d_shadow/*，没有接入 UI7。闭合网格使用表面距离和内部
判断；对不闭合网格仅判断表面接近，状态明确列出部件，不能声称内部判断完整。
对零面积退化三角形进行拓扑核验时剔除后，实际模型中 17/36 部件通过严格闭合
检查，其余 19 个仍有洞或非流形连接。例如左臂 link5 的边界跨约 0.168 m，不能
简单自动封洞后就声称模型与实物一致。

短时 TF 不可用时，只有在相邻历史姿态变化受限且时间差有界时才尝试上一次姿态，
并标记降级；也可在已有输入仍处于原始有效期内复用最后已过滤帧，**保留原始
时间戳**，不得借重发延长其寿命。明显运动、历史不足和超期不能伪称新鲜 TF。
合成测试覆盖历史而非最新姿态、不同高度的近邻点、短暂 TF 缺失、超期及恢复。

只读录制约 8.6 秒当前传感器与 TF，隔离域回放接真实点云转扫描和融合：前点云
76/76 帧完成，后扫描 127/128 帧完成（第一帧历史 TF 未建立），融合稳定观察
72 帧最大接收间隔约 130 ms，无内部队列丢帧；这些结果没有真实点标签。真实
NeuPAN 求解器接影子过滤及融合、模拟传感器时，160 ms 单部件 TF 间隙前后
58 个最终速度采样均非零。36 个模型各选取表面点、沿法线 ±5 mm 的 7176 个
合成样本均被识别；随机 20000 点三帧的纯几何平均约 5.36 ms/帧。所有这些均是
有限测试，不证明实机误删/漏滤率或复杂运动下的实时性。

尚未完成：非闭合部件深层点处理与模型覆盖策略、带标注的误删/漏滤对照、时间
精度与负载压力测试、正式导航链集成及全面回归。影子节点不用于控制，不应切换 UI7。
